# מבחן לילה & צ'ק ליסט נעילה

אפליקציית Web של עמוד יחיד (Single Page), בעברית ו-RTL מלא, מותאמת מובייל, עבור בית הספר
לסאונד ומוזיקה "מיקלט סאונד וקאמרה אובסקורה".

שני טאבים:

1. **מבחן לילה** — מבחן אינטראקטיבי על נהלי תרגול הלילה. בכל הרצה מוגרלות 15 שאלות אקראיות מתוך
   בנק של 32, סדר השאלות והתשובות מתערבב, וציון עובר הוא 100/100 בלבד. כל ניסיון (הצלחה או כישלון)
   נשלח לגיליון Google Sheets למעקב.
2. **צ'ק ליסט נעילה** — 25 משימות לפי סדר הנעילה בסוף הלילה, עם checkboxes ומונה התקדמות.
   הסימונים מתאפסים בכל רענון (אין שמירה).

## קבצים

| קובץ | תיאור |
|------|-------|

## הרצה מקומית

פשוט פותחים את `index.html` בדפדפן. אין תלות ב-build או ב-npm.

> אם משהו לא נטען, הריצו שרת סטטי מקומי מתיקיית הפרויקט, למשל:
> `python3 -m http.server 8000` ואז גשו ל-`http://localhost:8000`.

## אירוח (Hosting)

האפליקציה סטטית — אפשר לארח בכל שירות סטטי:

- **GitHub Pages**: Settings → Pages → Deploy from branch → בחרו את הענף ואת התיקייה `/root`.
- **Netlify / Vercel**: גררו את התיקייה או חברו את ה-repo. אין הגדרות build — פשוט מפרסמים כמו שהוא.

הגישה פתוחה לכל מי שיש לו את הקישור, ללא סיסמה. שדה "שם מלא" נדרש רק לפני התחלת המבחן.

## הוספת / עריכת שאלות

עורכים את `questions.js` בלבד. כל שאלה היא אובייקט במערך `QUESTION_BANK`:

**שאלה אמריקאית (`mc`)** — 3 או 4 אפשרויות, אחת נכונה:

```js
{"id": 33, "type": "mc", "question": "טקסט השאלה?", "options": ["א", "ב", "ג"], "correctIndex": 0}
```

- `correctIndex` = המיקום (מ-0) של התשובה הנכונה במערך `options`.

**שאלה נכון/לא נכון (`tf`)**:

```js
{"id": 34, "type": "tf", "question": "טקסט השאלה.", "correctAnswer": true}
```

- `correctAnswer` = `true` עבור "נכון", `false` עבור "לא נכון".

הקפידו על `id` ייחודי לכל שאלה. אין צורך לגעת בשום קובץ אחר — הערבוב, הבחירה האקראית
ומספר השאלות למבחן מנוהלים אוטומטית. (מספר השאלות למבחן נשלט ע"י הקבוע `QUESTIONS_PER_QUIZ`
בראש הסקריפט ב-`index.html`, כברירת מחדל 15.)

## פריסת ה-Web App (שמירת תוצאות ב-Google Sheets)

בצעו את הצעדים הבאים כדי לקבל את ה-URL שאליו האפליקציה שולחת את התוצאות:

1. היכנסו ל-[Google Sheets](https://sheets.google.com) וצרו **גיליון חדש** (למשל בשם "תוצאות מבחן לילה").
2. בתוך הגיליון: תפריט **Extensions → Apps Script**. נפתח עורך הסקריפטים.
3. מחקו את קוד ברירת המחדל בקובץ `Code.gs`, והדביקו במקומו את כל התוכן מהקובץ
   `apps-script/Code.gs` שבפרויקט הזה. שמרו (💾 / `Ctrl+S`).
4. לחצו על **Deploy → New deployment**.
5. ליד "Select type" (גלגל השיניים ⚙️) בחרו **Web app**.
6. הגדירו:
   - **Description**: לדוגמה `night-quiz`.
   - **Execute as**: `Me` (החשבון שלכם).
   - **Who has access**: **`Anyone`** — חשוב! בלי זה השליחה מהאפליקציה תיכשל.
7. לחצו **Deploy**. בפעם הראשונה תתבקשו **לאשר הרשאות** (Authorize access) — אשרו עם
   חשבון Google שלכם (אם מופיע "Google hasn't verified this app", לחצו *Advanced → Go to … (unsafe)*
   וזה תקין — זו האפליקציה שלכם).
8. העתיקו את ה-**Web app URL** שמופיע (מסתיים ב-`/exec`).
9. פתחו את `index.html`, ובראש הסקריפט הדביקו את ה-URL בקבוע:

   ```js
   // TODO: הדבק כאן את ה-URL של Google Apps Script Web App
   const SHEETS_WEBAPP_URL = "https://script.google.com/macros/s/XXXXX/exec";
   ```

10. שמרו ופרסמו מחדש את האפליקציה. מעכשיו כל סיום מבחן יופיע כשורה חדשה בגיליון.

**בדיקה מהירה:** פתחו את ה-URL בדפדפן — אמור להופיע `{"status":"alive",...}`.
עשו מבחן באפליקציה — שורה חדשה אמורה להתווסף לגיליון.

> **עדכון הקוד בעתיד:** אם תערכו את `Code.gs`, בצעו **Deploy → Manage deployments →
> עריכה (✏️) → Version: New version → Deploy** כדי שהשינוי ייכנס לתוקף (ה-URL נשאר אותו דבר).

### הערות טכניות

- האפליקציה שולחת POST במצב `no-cors` (Apps Script אינו מחזיר כותרות CORS). לכן השליחה
  מתבצעת אך אין קריאת תשובה — זה תקין ומספיק לצורך הרישום.
- אם השליחה נכשלת (בעיית רשת וכו') התלמיד אינו נחסם ואינו רואה שגיאה; נרשם רק לוג שקט בקונסול.
- אם `SHEETS_WEBAPP_URL` ריק, האפליקציה פשוט לא שולחת (ומדפיסה זאת לקונסול) — כל שאר הפונקציונליות עובדת.
